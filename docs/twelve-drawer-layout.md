# Two six-drawer catalogs

On **Drawers**, expand **Set up two six-drawer catalogs**. Review the filing
plan, acknowledge it, and choose **Set up twelve drawers**. Accounts with
existing custom sorter rules must review/edit those rules on Locations instead;
the setup never replaces an existing rule set.

The setup keeps the IDs and contents of Drawer 1–6 and adds Drawer 7–12 as
native drawer locations. It changes no inventory quantities, placement flags,
slots, or audit results. It does not run the sorter. No database migration is
required.

| Native location | Physical label | Set codes |
|---|---|---|
| Drawer 1 | A1 | Numbers + A–B |
| Drawer 2 | A2 | C |
| Drawer 3 | A3 | D–E |
| Drawer 4 | A4 | F–H |
| Drawer 5 | A5 | I–L |
| Drawer 6 | A6 | M |
| Drawer 7 | B1 | N–R |
| Drawer 8 | B2 | S |
| Drawer 9 | B3 | T–V |
| Drawer 10 | B4 | W–Z |
| Drawer 11 | B5 | Basic lands |
| Drawer 12 | B6 | Tokens, substitutes, physical proxies |

Oversized cards get a separate location. These rules cover InventoryRow cards;
tokens recorded through the separate Tokens feature remain managed there.
The first matching rule wins: oversized, token/proxy, basic, then set-code
prefix. An empty or unknown set code falls back to Drawer 1 for review.
Prices and languages do not change the set-code destination. New set codes
are covered automatically by their initial letter.

Native addresses remain `Drawer N`; edit the location **Note** to change its
filing label. Edit the sorter rules to change destinations. Extended catalogs
(any native drawer above 6) use set/collector-number slot order and keep all
imported copies rather than automatically splitting inexpensive duplicates
into Bulk. Six-drawer accounts keep the existing sorting and intake policy.

When ready, apply the sorter and use Pending to carry out and confirm physical
moves. This is not an ownership audit. Decks and locations marked **Leave this
alone**, including the usual Bulk box, stay separate. Move existing Bulk cards
explicitly when filing them into the catalogs.

Each native drawer page links to **Audit this drawer**. Audit one set at a time
and count identical printing/finish copies together. “Mark missing” records a
discrepancy without reducing inventory quantity; resolve confirmed shortages
separately. Do not move cards in an audit's scope while that audit is active.
