How the ratings work

Each {{ 'deck' if rank_by == 'decks' else 'player' }} starts at 1,500. OpenSkill updates ratings in game order using finishing position, opponent strength, and uncertainty. Beating stronger opponents can earn more credit, and finishing ahead of someone can help even without winning. Ratings reflect the combination of pilot and deck, not isolated player skill.

For recorded ties below first place, an elimination gap over 60 seconds separates finishing positions when the event history is complete. Explicit result edits take precedence. Shared firsts and ties without enough evidence remain tied. This adjusts the rating calculation, not the saved game results.
